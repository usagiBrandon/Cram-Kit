# Cram-Kit
How to skip class and have a 4.33 GPA (kinda) (method unpatched 2026)

https://usagibrandon.github.io/Cram-Kit/

Panopto transcript and Canvas slide grabber with instructions on how to create (and use) a Claude project for studying. 

Main idea:
1. grab transcripts and lecture slides
2. create a context doc for a claude project using transcripts and slides (So claude knows the scope of the course)
3. upload all lectures + context doc into a claude project and ask questions to study

Additionally: 
1. Make an interactive study guide OR generate an overview of what happened in each lecture (using the downloadable instructions that you upload to claude project)
2. Make anki flashcards
3. Upload example test questions/practice midterms, etc then generate new practice tests AND analyze practice exams for key topics to focus on
