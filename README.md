# Cram-Kit
How to skip class and have a 4.33 GPA (kinda) (method unpatched 2026)

https://usagibrandon.github.io/Cram-Kit/

Panopto transcript and Canvas slide grabber with instructions on how to create (and use) a Claude project for studying. 

Main idea:
1. grab transcripts and lecture slides
2. create a context doc for a claude project using transcripts and slides (So claude knows the scope of the course)
3. upload all lectures + context doc into a claude project and ask questions to study

Additionally: 
1. Make an interactive study guide OR generate an overview of what happened in each lecture (using the downloadable instructions that you upload to claude project)
2. Make anki flashcards
3. Upload example test questions/practice midterms, etc then generate new practice tests AND analyze practice exams for key topics to focus on

## How the site is built
- `index.html`: main page (Taipei night-drive background, clock, pomodoro, guide, toolkit, music)
- `simple.html`: the "too many effects?" version (plain layout, same guide and tools)
- `assets/core.js`: guide steps, course card that fills every prompt, Anki planner, built-in lofi music
- `assets/mocks.css`: the animated "how to do it" diagrams
- `assets/data.js`: generated by `node build.js` from `src/` (bookmarklets + prompts). Don't edit by hand.
- `src/`: bookmarklet code and prompt templates
- `music/`: drop MP3s here and list them in `music/playlist.json`, e.g. `[{"file": "track.mp3", "title": "Late night"}]`
- Front-page art: put an image you have the rights to at `hero.png` (or `.webp`/`.jpg`) in the repo root. It gets pixelated and neon-graded automatically. No image = no art, the page still works.

To change prompts or bookmarklets: edit `src/`, run `node build.js`, commit, push.
