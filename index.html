Cram-Kit

Grab every lecture transcript and slide deck in one click each. Then turn them into a Claude tutor that knows what happened in class and what's on the exam.

Use a computer with Chrome, Edge or Firefox. Nothing to install. Everything runs in your browser.

  1. Show your bookmarks bar: Cmd+Shift+B (Mac) or Ctrl+Shift+B (Windows).
  2. Drag both buttons onto the bar. Don't click them here.

Panopto

Get the transcripts

  1. Open your course's Panopto folder and wait for the list to load. (More than 25 lectures? Set Results per page to the max.)
  2. Click ⬇ Get transcripts.
  3. A zip downloads: one .md per lecture (with timestamps) and one combined file.
3
Canvas

Get the slides

  1. Open any page in the course on Canvas.
  2. Click ⬇ Get slides. A list of every course file pops up.
  3. Pick Best version (recommended), Only PPTX or Only PDF, then press Download.
  4. First time only: Chrome blocks everything after the first file. Click the blocked-download icon at the right of the address bar → Always allow → press Retry.
PPTX vs PDF: PPTX includes text hidden behind click-to-reveal animations, so it's better for Claude. PDF is better for GoodNotes.
Something not working?
  • Nothing happens: reload the page, wait for it to load, then click again. Safari is fussy, so use Chrome.
  • "No recordings found": you're not on a Panopto folder, or it hasn't loaded yet.
  • Lectures "without captions": Panopto hasn't made them yet. Try again tomorrow.
  • Only one slide downloaded: do the "Always allow" step above, or use the ⬇ next to each file.
  • No files on Canvas: the prof hosts slides elsewhere. Check "External links" in the pop-up.

Is it safe?

The buttons run inside your own logged-in Panopto or Canvas tab and use their built-in download links. They never see your password, and nothing is sent to this site.

Got your files? Go to ② Create the Claude project →

Check your syllabus first. Some profs don't allow lecture recordings or transcripts in AI tools. If so, use slides only. It all still works.

New chat, outside any project

Build the lecture context doc

Turns each lecture into one page: what happened, what was said beyond the slides, and what's on the exam.

  1. Download the doc skeleton and open it in a text editor.
  2. Start a new chat. Attach the transcripts and slides for 2–4 lectures (1–2 on Free).
  3. Paste the builder prompt, fill in the brackets at the top, and send. Type continue if it stops.
  4. Paste the result into your doc. Repeat in a new chat for the next lectures.

Upload files

  • ✅ Learning objectives, if you have them

4

Ask it things

New chat inside the project. Try:

  • What happened in Lecture 7?
  • I missed class on Oct 20, catch me up
  • Quiz me on Lectures 10–12, exam style
  • What's on the final? Make a checklist
  • Is X tested?
Answers end with a scope tag like 🎯 on the exam (L6, 23:10) or 🚫 not tested.
