# Practice Exam (prompt)

> **How to use:** inside your course project, after you've saved the **Exam blueprint** (from the past paper analysis) to the project files. Start a new chat, fill in the brackets, paste everything below the line, and send. Do the exam timed, on paper or in the artifact, then send your answers to get it marked.

---

Make a **practice [Midterm 2 / Final / Quiz 4]** for **[COURSE CODE]** covering **[Lectures N–M]**.

**Use:** the Exam blueprint and the lecture context doc in project knowledge, plus any past exams I've attached.

## Match the real exam exactly
- Copy the **format of the most representative real exam** (Tier A in the blueprint; Tier B if there's no Tier A): the same sections in the same order, the same number and types of questions, the same point values, time limit, instructions, and answer format (bubble, short answer lines, show-your-work boxes).
- Match the prof's **wording style, difficulty and recall/application mix**. If the real exams use scenarios, tables, graphs or diagrams, so does this one (draw them as inline SVG).
- **Do not copy past questions.** Write new questions that test the same ideas in the same way. Change the scenario, the numbers, or the angle.
- If the only practice material doesn't look like the real exam (the blueprint will say), follow the blueprint's format, not the practice material's.

## Content
- Split topics in the same proportions as the blueprint's predicted topic mix. Weight 🎯/⭐ items and the "Top 10" most.
- Include the prof's usual traps and at least one question on a "taught but never tested yet" topic.
- Only use content from the covered lectures. Nothing marked 🚫.
- For multiple choice: plausible distractors drawn from real misconceptions, one clearly best answer, answers spread evenly across A–D.

## Output
1. **The exam** as a clean, printable HTML artifact (looks like a real exam paper: header, instructions, time, marks per question). Add an optional **"Take it here"** mode with a countdown timer and answer boxes.
2. **Answer key in a separate artifact**, so I don't see it while I write. For each question: the answer, why each wrong option is wrong, the marking scheme for written answers (what earns each mark), the topic and lecture, and the source it's modelled on (e.g. `like MT1-2024 Q7`).

## When I send my answers
Mark them strictly, like the prof would. Then give me:
- my score, overall and by topic
- each mistake: what I wrote, the correct idea, and *why* I got it wrong (didn't know it, misread the question, mixed up two terms, calculation slip)
- the 3 topics to study next, ranked
- Anki cards for every mistake, in the same `.txt` import format as the Anki deck prompt, tagged `mistake`
